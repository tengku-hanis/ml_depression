# Development of a Machine Learning-Based Screening Model for the Risk of Depression Among the Elderly in China

This repository contains the R code for the publication. There are 4 folders in this repository:

1. Feature selection: This folder contains the R script used for feature selection.
2. ML models: This folder contains all 8 machine learning algorithms tested in this study
3. Final model: This folder contains the R script for the final model with its finalised hyperparameters.
4. Explainable mode: This folder contains an R script for the explainable model developed in this study.
